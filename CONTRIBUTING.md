# Contributing to Adii-Digital

Thanks for helping improve the Adii Digital website. This is a small static site, so the process is deliberately simple.

## How to make a change

1. Create a new branch from `main` with a short, clear name, e.g. `fix/mobile-menu` or `content/hero-copy`.
2. Make your change, keeping it focused on one thing.
3. Preview the site locally (open `index.html`, or serve the folder with `python3 -m http.server`) and check it on a mobile-width screen as well as desktop.
4. Commit with a clear message that says what changed and why.
5. Open a pull request into `main` and fill in the pull request template.

## Ground rules

- Do not push directly to `main`.
- Never commit passwords, API keys, or other secrets — the `.gitignore` blocks common secret files, but please double-check before committing.
- Keep the site dependency-free: plain HTML, CSS, and vanilla JavaScript unless a change is agreed first.
- Do not add claims about clients, results, awards, or partnerships that are not verified and approved by the agency.
- Keep file sizes small and check that images (if any are added) are compressed.

## Reporting a problem

Open an issue using the bug report or feature request templates under **Issues**.
